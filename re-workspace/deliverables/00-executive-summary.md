## What Is webm.lua?

`webm.lua` is an mpv Lua script that adds an interactive video clip encoder to the mpv media player. Users press a configurable key (default: W) to open an OSD overlay, select start/end times and an optional crop region, configure encoding options, and produce a clip in one of seven output formats.

## Origin

The original MoonScript source is not included in the repository.

## Key Capabilities

- Interactive OSD UI with four pages: main menu, crop selection, options, preview
- Seven output formats: WebM VP8, WebM VP9, MP4 H.264, MP4 NVENC, MP3, GIF, (raw — broken)
- 2-pass encoding for WebM VP8 and MP4 formats
- Real-time progress overlay during encoding
- Live preview with crop applied
- 24 configurable options via script-opts or IPC
- HLS stream support via cache dumping

## Security Assessment

No malware or malicious behavior detected. The primary security concern is the **IPC handler (mpv-webm-set-options)** which accepts arbitrary JSON without validation — any mpv script with IPC access can override all options including `additional_flags`. Risk is LOW for standalone use; MEDIUM in environments with multiple untrusted scripts.

## Compatibility

- Requires Lua 5.1 or LuaJIT (uses `math.ldexp` which is deprecated in Lua 5.3+)
- Cross-platform: Windows/POSIX differentiation via `package.config`
- Requires mpv with mp.utils.subprocess support
