Top Recommendation

#1

Explicit format registry seam (Candidate 2)

This is the smallest change with the highest defect impact — it directly fixes FIND-002 (the nil crash that blocks the primary user workflow) and FIND-003 at a single seam, while establishing the first explicit interface in a codebase that currently has none.

#2

Deepen encode() pipeline (Candidate 1)

The 189-line encode() function is the central maintenance liability — it fails the deletion test badly (every concern reappears in the same place), contains the FIND-001 bitrate bug, and cannot be tested without a live mpv process; a 3-entry seam would immediately improve all three problems.

#3

Subprocess execution module (Candidate 3)

Three real adapters already exist, satisfying the two-adapter rule for a real seam; tackle after the encode() pipeline split since the subprocess choice currently lives inside encode().
